# Avaliação da extração (fora do T2)

A avaliação da qualidade da extração de prontuários com o conjunto AnonyMED-BR foi **cortada do T2** (decisão D15 de
[docs/PLANO.md](../docs/PLANO.md)): a spec não pede, e a licença de uso e redistribuição do conjunto continua
pendente. O conjunto continua fora do git (`data/anonymedbr/` está no `.gitignore`).

O plano original (adapter dos 500 pares, splits 100/400, amostra de 60 para revisão humana) está preservado em
[docs/historico/](../docs/historico/), para uma continuação no TCC.
